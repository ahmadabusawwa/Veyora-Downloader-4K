حمّل

الصق رابط الفيديو واختر الجودة اللي تناسبك، والتحميل يبدأ فورًا.

ترجم

افهم المحتوى بأي لغة، مع ترجمة جاهزة تظهر مع الفيديو.

استمتع

شغّل فيديوهاتك مباشرة من التطبيق بدون ما تحتاج برنامج ثاني.

كيف أثبّت فيورا؟

  1. حمّل الملفاضغط زر التحميل وانتظر انتهاء التنزيل.
  2. شغّل المثبّتافتح الملف واتبع خطوات التثبيت.
  3. ابدأافتح فيورا والصق أول رابط.

للتحميل بجودة عالية: ثبّت FFmpeg

خطوة لمرة وحدة فقط. انسخ الأمر وشغّله في PowerShell.

winget install Gyan.FFmpeg
  1. افتح PowerShell كمسؤولاضغط زر Start واكتب PowerShell، كليك يمين عليه واختر Run as administrator.
  2. الصق الأمراضغط نسخ الأمر ثم كليك يمين داخل النافذة للصق، واضغط Enter وانتظر ينتهي.
  3. أعد فتح فيوراأغلق PowerShell والتطبيق وافتحهم من جديد، وبعدها ابدأ التحميل.
