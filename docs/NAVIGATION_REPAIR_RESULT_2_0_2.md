## الأسباب والإصلاحات

| المشكلة | السبب المؤكد من الكود | الإصلاح |
|---|---|---|
| Playlist تفتح تحميل الفيديو | زرها يستدعي home_mode(False) | صفحة مستقلة فعلية تستخرج قائمة yt-dlp وتحدد عناصرها وتضيفها لطابور التنزيل |
| الضغط المتكرر وإعادة التحميل | show_tab يهدم عناصر المحتوى ويعيد إنشاء الصفحة حتى عند طلب الصفحة المفتوحة | مدير صفحات يحتفظ بسبع صفحات، يمنع إعادة الدخول، والطلب المتكرر لا يعيد البناء |
| اختفاء الملف والإعدادات | متغير مسار الملف محلي وعمره مرتبط بعناصر الصفحة المهدومة | حفظ نموذج المدخلات مستقلًا عن الواجهة وإعادة استخدام الصفحة |
| اختفاء تقدم الترجمة | مراجع الحالة والأزرار مرتبطة بالصفحة، مع مؤقتات محلية تتكرر | مدير مهام مركزي يحتفظ بالهوية والمسار والحالة والمرحلة والتقدم والوقت والنتيجة والخطأ؛ العرض يقرأه من خيط Tk الرئيسي |
| تكرار المهام أو إلغاء مهمة خاطئة | حالة العرض ليست مرجعًا مركزيًا كافيًا | قفل وحارس بدء ومعرف مهمة وربط الإلغاء بنوع المهمة الصحيح |
| تكلفة التنقل | إعادة تلوين جميع الأزرار وقراءة السجل وبناء صفوفه على الواجهة | تحديث الأزرار المتغيرة فقط، قراءة السجل في الخلفية وبناء دفعات صغيرة وصفحات |
| بطء التصغير والاستعادة | لم يثبت سبب مستقل متعلق بحدث Resize، ولم نجد تحميل نماذج خاصًا بالاستعادة | أزلنا هدم الصفحات والمؤقتات المتكررة وقللنا الرسم غير المرئي؛ تحققنا من 20 دورة فعلية أثناء الترجمة |
| زر بدء معطل لحظيًا بعد النهاية | اكتمال العامل المركزي يسبق دورة تحديث الزر التالية | طلب الصفحة المفتوحة ينعش حالة المهمة دون إعادة بناء؛ أضيف اختبار للحظة السباق |
| آخر توقيت يتجاوز الفيديو | مقطع التعرف قد يتجاوز مدة الصوت | حصر المقاطع ضمن مدة الصوت وتغيير مفتاح cache لتجنب نتائج قديمة غير محصورة |

العمليات الثقيلة في الخلفية. لا تحديث Tk من عامل خلفي، ولا sleep داخل مسار واجهة الإنتاج. مغادرة الترجمة لا تلغيها. إصلاح تشكيل العناوين العربية محفوظ، ولا تغيير مقصود للوحة الألوان والتصميم العام.

## حدود النتيجة

هذه نتائج جهاز Windows CI وفيديو صناعي منخفض الدقة مدته 3 دقائق؛ ليست ضمانًا لكل الأجهزة الضعيفة أو الفيديوهات الطويلة أو جودة الكلام البشري والموسيقى. الترجمة الآلية حقيقية لكنها ليست مصححة لغويًا: ترجم النموذج عبارة save the subtitles أحيانًا إلى «إنقاذ العنوان الفرعي». هذا التقرير يثبت مسار المعالجة واستقرار الحالات المختبرة، ولا يدعي حل جودة النموذج اللغوية أو اعتماد جميع المواقع الخارجية. اختبار Playlist هنا بمحتوى محلي مصرح؛ لا يضمن كل موقع.
