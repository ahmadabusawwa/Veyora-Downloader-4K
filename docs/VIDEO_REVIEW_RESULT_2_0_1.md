## نطاق الاختبار

Windows Server 2022 على عامل GitHub Actions، وPython 3.12، ونسخة PyInstaller مُثبّتة عبر Inno Setup. أُنشئ صوت إنجليزي محلي باستخدام SAPI، ثم وُضع داخل فيديو أزرق مدته **90 ثانية**، بدقة **320×180** و15 إطارًا/ثانية، وباسم ملف عربي.

استدعت الأتمتة زر بدء المعالجة الحقيقي في الواجهة، واستخدمت **faster-whisper base.en، وArgos/CTranslate2، وFFmpeg فعليًا**. لم تستبدل هذه المكونات أو نتائجها بكائنات محاكية.

جُهزت النماذج قبل الاختبار. أثناء اختبار الصوت، فُعّلت قواعد Windows Firewall لحظر الاتصالات الصادرة من البرنامج المثبّت وعماله والبرامج المضمّنة، مع `HF_HUB_OFFLINE=1`. يحفظ ملف `firewall-evidence.json` بيانات القواعد التي تحقّق منها الاختبار. أُزيلت قواعد الاختبار المؤقتة بعد انتهاء الفحص.

## جودة الترجمة وحدود الاستنتاج

المسار يُنتج ترجمة حقيقية، لكن الجودة ليست مثالية. مثلًا، عبارة `save the subtitles` أُنتجت في بعض المقاطع بصيغة «إنقاذ العنوان الفرعي» بدل «حفظ الترجمة». هذا خطأ لغوي من النموذج، ويجب مراعاة مراجعة النصوص قبل الاستخدام المهني.

العينة صوت مولّد محليًا ومتكرر؛ ليست شهادة دقة للصوت البشري أو اللهجات أو الضوضاء. لم يُختبر هنا تفريغ عربي/تركي/كوري فعلي، أو فيديو المستخدم ذي الـ17 دقيقة، أو استجابة جهاز ضعيف بعينه. ولا يمكن تعميم زمن الـ34 ثانية على أجهزة المستخدمين أو فيديوهات عالية الدقة.

فشلت محاولة أسبق قبل تشغيل الصوت بسبب رفض إعداد قاعدة جدار حماية عبر CIM. صُحح إعداد بيئة الاختبار باستخدام مسار كامل وواجهة Firewall COM، ثم نجحت المحاولة المشار إليها أعلاه. لم تُحتسب المحاولة الفاشلة كنجاح.
